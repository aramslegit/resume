# Stratae

Personal portfolio + resume site built with React/Vite, with:

- **Internationalization** (currently `en`, `nl`, `fr`)
- **Themeable UI** (palette themes like `linear`, `paper`, etc.)
- **Downloadable resume PDFs** generated from a print-friendly route

## Local development

This project targets **Node.js 24** (see `.nvmrc`).

```sh
nvm use
npm install
npm run dev
```

The dev server runs on `http://localhost:8080`.

## Scripts

- **`npm run dev`**: start the Vite dev server (runs a quick “generate PDFs if missing” step via `predev` — install Playwright if it prompts)
- **`npm run build`**: production build to `dist/`
- **`npm run preview`**: preview the production build locally
- **`npm run lint`**: ESLint
- **`npm run format`** / **`npm run format:check`**: Prettier
- **`npm test`**: Vitest
- **`npm run pdf:generate`**: generate “latest” resume PDFs
- **`npm run pdf:archive`**: generate timestamped archived PDFs

## Resume PDF generation

PDFs are generated by rendering `"/print/resume"` in a headless browser (Playwright) and saving the result into `public/` so they can be served as static assets.

### One-time setup

```sh
npm i -D playwright
npx playwright install chromium
```

### Generate latest PDFs

```sh
npm run pdf:generate
```

Outputs:

- **Latest PDFs**: `public/resume/`
- **Archived PDFs**: `public/archive/` (when using archive mode)

Filename convention (see `src/config/resumeNaming.js`):

- Latest: `Aram_Mamian_Resume_<lang>_<theme>.pdf`
- Archive: `Aram_Mamian_Resume_<lang>_<theme>_<timestamp>.pdf`

### Useful flags

You can pass options after `--`:

```sh
# Only specific languages
npm run pdf:generate -- --langs en,nl

# Only specific themes
npm run pdf:generate -- --theme linear,paper

# Archive instead of overwriting latest
npm run pdf:generate -- --archive

# Reuse an already-running server (skip build/preview)
npm run pdf:generate -- --base-url http://127.0.0.1:8080 --skip-build --skip-preview
```

Supported flags:

- **`--langs` / `--languages`**: comma-separated list (default: `en,nl,fr`)
- **`--theme`**: comma-separated list (default: `linear,classic,paper,terminal`)
- **`--archive`**: write timestamped PDFs to the archive directory
- **`--skip-build`**: don’t run `npm run build`
- **`--skip-preview`**: don’t run `npm run preview`
- **`--base-url`**: base URL to render from (defaults to the preview server)
- **`--port`**: preview port (default: `4173`)
- **`--force`**: overwrite even if outputs exist
- **`--if-missing`**: only generate when an expected output is missing (used by `predev`)

## Releases (Semantic Versioning)

This repo uses **semantic-release** via GitHub Actions (`.github/workflows/release.yml`).

- **`development`**: pre-releases like `1.2.3-dev.4`
- **`main`**: stable releases like `1.2.3`

Version bumps follow **Conventional Commits**:

- **`fix:`** → patch (\(x.y.\*\))
- **`feat:`** → minor (\(x.\*.0\))
- **`feat!:`** or **`BREAKING CHANGE:`** → major (\(\*.0.0\))

## Deployment

This is a static Vite app:

- Run **`npm run build`**
- Deploy the `dist/` directory to any static host (Netlify, Vercel static output, GitHub Pages, S3/CloudFront, etc.)
